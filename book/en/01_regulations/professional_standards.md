# Relationship with Professional Standards

The Department page recommends following a model adapted from professional standards for Computer Engineering projects {cite:p}`dia_tfg_informatica_2025_2026`.

The official source for this professional context is the CPIICM page on Computer Engineering project standards. It presents the Technical Standard for Computer Engineering Projects prepared by the Professional Association of Computer Engineers of the Community of Madrid and the Official Association of Computer Engineers of the Basque Country {cite:p}`cpiicm_normativa_proyectos_2026`.

Specifically, the current Department documentation for the TFG should be understood as an academic subset adapted from those professional standards. For the documentary details, this book uses as a technical reference the CPIICM Technical Standard PDF for preparing Computer Engineering project documentation {cite:p}`cpiicm_nt_v2`, in relation to Standard CCII-N2016-02 for preparing Computer Engineering project documentation {cite:p}`ccii_n2016_02`.

## What Does This Mean for a TFG?

It does not mean that the TFG is a complete formally certified professional project or that every document from a certified project must be reproduced. It means that the TFG guide selects and adapts the elements that make academic sense:

- The report connects and justifies the whole project.
- The annexes develop the technical part in greater detail.
- Relevant decisions must be traceable.
- Requirements, analysis, design, planning, testing, and security are not documentary decoration.
