# Citations and Bibliography

In this guide the criterion is deliberately strict: **a serious TFG should use a bibliography manager**. Mendeley and Zotero are reasonable options; choosing one or the other is less important than not managing references by hand.

Managing citations manually usually leads to errors:

- References that appear in the bibliography but are not cited.
- In-text citations that do not appear in the bibliography.
- Incomplete dates, authors or titles.
- Citation styles applied inconsistently.
- URLs without access dates.
- Bibliographies that differ between Word, PDF and LaTeX.

## Minimum Recommended Workflow

1. Install a bibliography manager.
2. Capture sources from the browser.
3. Review the metadata before accepting the reference.
4. Organize sources in folders or collections for the TFG.
5. Insert citations from the Word plugin or export BibTeX for LaTeX/Overleaf.
6. Generate the bibliography automatically.
7. Check at the end that every citation has an entry and every entry is cited.

A comfortable workflow with Mendeley is:

- Use Mendeley Reference Manager as the central library {cite:p}`mendeley_reference_manager`.
- Install Mendeley Web Importer in Chrome or a compatible browser to capture articles, pages and PDFs {cite:p}`mendeley_web_importer`.
- Review authors, title, year, DOI, URL and access date.
- In Word, insert citations with the Mendeley add-in.
- In LaTeX or Overleaf, export a collection to BibTeX or keep a synchronized `.bib` file.

The critical point is not clicking "import". The critical point is reviewing. Many importers confuse capitalization, web pages, conference names or corporate authors.

## Bibliographic Style

If your supervisor, committee or current regulations require a specific style, use that. The DIA documentation guide states that the bibliography should be cited properly following whichever standard is considered most appropriate {cite:p}`dia_documentacion_tfg_v2`.

This book uses an **APA-inspired author-year system**. A parenthetical citation should appear as *(Author, year)* and a narrative citation can be integrated as *Author (year)*. The final bibliography is displayed without visible numbering and with a hanging indent, so it is closer to the usual appearance of an APA reference list.

```{admonition} APA In This Book
:class: note

The book configuration forces author-year citations with parentheses and hides numeric bibliography labels in the final web list. Even so, it is better to describe this as *APA-like* or *author-year* style, not as strict APA 7th edition compliance, because the list is generated by Jupyter Book/Sphinx from BibTeX.
```

In a TFG report, author-year citations make it easier to see where each idea comes from without forcing the reader to jump continuously to a numbered list. If your supervisor, committee or an official template requires IEEE or another style, that requirement takes precedence. In any case, consistency matters more than personal preference.

```{important}
AI can help you detect incomplete references, but it must not invent sources. Every reference must exist, be relevant and have been consulted by the author.
```
