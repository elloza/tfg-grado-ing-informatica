# Cómo citar

Si utilizas este libro, puedes citarlo así:

> Lozano Murciego, A. (2026). *Documentación de un TFG en Ingeniería Informática en tiempos de IA*. Universidad de Salamanca. CC BY 4.0.

## BibTeX

```bibtex
@book{lozano2026tfgia,
  author = {Lozano Murciego, Álvaro},
  title = {Documentación de un TFG en Ingeniería Informática en tiempos de IA},
  year = {2026},
  publisher = {Universidad de Salamanca},
  note = {Guía no oficial, CC BY 4.0}
}
```

## Citar páginas concretas

Para citar una página concreta, añade el título de la página y la fecha de consulta. Este libro es un documento vivo, por lo que conviene citar también el repositorio o la versión consultada cuando esté disponible.
