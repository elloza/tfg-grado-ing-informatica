# Como citar

Si utilizas este libro, puedes citarlo asi:

> Lozano Murciego, A. (2026). *Documentacion de un TFG en Ingenieria Informatica en tiempos de IA*. Universidad de Salamanca. CC BY 4.0.

## BibTeX

```bibtex
@book{lozano2026tfgia,
  author = {Lozano Murciego, Alvaro},
  title = {Documentacion de un TFG en Ingenieria Informatica en tiempos de IA},
  year = {2026},
  publisher = {Universidad de Salamanca},
  note = {Guia no oficial, CC BY 4.0}
}
```

## Citar paginas concretas

Para citar una pagina concreta, anade el titulo de la pagina y la fecha de consulta. Este libro es un documento vivo, por lo que conviene citar tambien el repositorio o la version consultada cuando este disponible.
