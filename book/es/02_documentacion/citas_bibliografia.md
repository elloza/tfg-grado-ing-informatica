# Citas y bibliografia

En esta guia el criterio es deliberadamente estricto: un TFG serio debe usar un gestor bibliografico. Mendeley y Zotero son opciones razonables; elegir uno u otro es menos importante que no gestionar referencias a mano.

Gestionar citas manualmente suele terminar en errores:

- Referencias que aparecen en bibliografia pero no estan citadas.
- Citas en el texto que no aparecen en bibliografia.
- Fechas, autores o titulos incompletos.
- Cambios de estilo aplicados a medias.
- URLs sin fecha de consulta.
- Bibliografias inconsistentes entre Word, PDF y LaTeX.

## Flujo minimo recomendado

1. Instala un gestor bibliografico.
2. Captura fuentes desde el navegador.
3. Revisa los metadatos antes de aceptar la referencia.
4. Organiza las fuentes por carpetas o colecciones del TFG.
5. Inserta citas desde el plugin de Word o exporta BibTeX para LaTeX/Overleaf.
6. Genera la bibliografia automaticamente.
7. Revisa al final que toda cita tiene entrada y toda entrada esta citada.

## Mendeley como ejemplo

Un flujo comodo con Mendeley es:

- Usar Mendeley Reference Manager como biblioteca central {cite:p}`mendeley_reference_manager`.
- Instalar Mendeley Web Importer en Chrome o navegador compatible para capturar articulos, paginas y PDFs.
- Revisar autores, titulo, ano, DOI, URL y fecha de consulta.
- En Word, insertar citas con el complemento de Mendeley.
- En LaTeX u Overleaf, exportar una coleccion a BibTeX o mantener un archivo `.bib` sincronizado.

El punto critico no es pulsar "importar". El punto critico es revisar. Muchos importadores confunden mayusculas, paginas web, nombres de conferencia o autores corporativos.

## Zotero como alternativa

Zotero es una alternativa muy solida, especialmente si quieres un ecosistema abierto, buena captura desde navegador y exportacion BibTeX/BibLaTeX {cite:p}`zotero_docs`.

## Estilo bibliografico

Si tu tutor o normativa exige un estilo, usa ese. Si no hay indicacion concreta, APA es una opcion razonable para una memoria academica. En cualquier caso, la consistencia pesa mas que la preferencia personal.

```{important}
La IA puede ayudarte a detectar referencias incompletas, pero no debe inventar fuentes. Toda referencia debe existir, ser pertinente y haber sido consultada por el autor.
```
