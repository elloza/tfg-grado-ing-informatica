# Objeto y objetivos

Define un objetivo principal y subobjetivos medibles. Evita objetivos vagos como "aprender una tecnología" si no se traducen en resultados verificables.

El objetivo principal debe expresar la contribución del TFG. Los subobjetivos ayudan a comprobar si el trabajo se ha completado: implementar un módulo, evaluar una alternativa, diseñar una arquitectura, validar un prototipo o documentar un procedimiento reproducible.
