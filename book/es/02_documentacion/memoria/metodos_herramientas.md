# Métodos, herramientas y modelos

Explica la metodología de desarrollo y las herramientas relevantes. No hace falta explicar qué es Visual Studio Code si no afecta al proyecto; sí hace falta explicar por qué se eligió una arquitectura, una librería de IA o un framework.

Incluye aquí solo las herramientas que influyen en el resultado, la calidad, la reproducibilidad o la forma de trabajar. Las herramientas obvias pueden mencionarse, pero no necesitan una explicación enciclopédica.
