# A5. Otros anexos

Aquí pueden ir manuales, instrucciones de instalación, documentación de API, estructura del repositorio, ejemplos de datos, material complementario o evidencia de pruebas.

El criterio es simple: si ayuda a instalar, ejecutar, revisar, mantener o reproducir el TFG, puede tener sentido como anexo. Si solo aumenta volumen sin aportar evidencia, probablemente sobra.
