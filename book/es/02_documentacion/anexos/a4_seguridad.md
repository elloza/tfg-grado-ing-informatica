# A4. Plan de seguridad

Debe tratar seguridad cuando aplique:

- Datos personales.
- Autenticación y autorización.
- Dependencias.
- Secretos y configuración.
- Copias de seguridad.
- Riesgos legales o técnicos.
- Medidas adoptadas.

Si el TFG no tiene implicaciones de seguridad relevantes, se debe justificar de forma clara. No todos los proyectos requieren el mismo nivel de profundidad, pero ignorar la seguridad sin explicación suele ser mala señal.
