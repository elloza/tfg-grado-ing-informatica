# Correspondencias antigua vs actual

La estructura actual no rompe con la antigua: la compacta, la adapta y cambia el peso de algunos documentos. Esta tabla ayuda a reutilizar buenas practicas de ITIS/PFC sin seguir una estructura obsoleta.

| En la guia antigua | Encaje en la estructura actual | Comentario practico |
|---|---|---|
| Introduccion | Introduccion de la memoria | Presenta dominio, motivacion, problema y estructura del documento. |
| Objetivos del proyecto | Objeto y objetivos | Distingue objetivo principal, subobjetivos y objetivos personales si aportan valor. |
| Conceptos teoricos | Antecedentes / situacion actual | Solo incluye teoria necesaria para entender el TFG. |
| Tecnicas y herramientas | Metodos, herramientas y modelos | No listes herramientas obvias; explica las que afectan a decisiones tecnicas. |
| Aspectos relevantes del desarrollo | Solucion propuesta / organizacion | Debe explicar decisiones, problemas encontrados y evolucion del trabajo. |
| Trabajos relacionados | Antecedentes / estado del arte | Especialmente importante en TFGs de investigacion o con tecnologia novedosa. |
| Conclusiones y lineas futuras | Conclusiones y trabajo futuro | Debe responder a los objetivos, no limitarse a cerrar con frases genericas. |
| Plan del proyecto software | Gestion del proyecto / Anexo A3 | Planificacion, hitos, esfuerzo, coste temporal y estimaciones. |
| Especificacion de requisitos | Anexo A1 | Requisitos funcionales, no funcionales, historias, casos de uso o equivalentes. |
| Especificacion de diseno | Anexo A2 | Arquitectura, modelo de datos, componentes, interfaces y decisiones de diseno. |
| Documentacion tecnica de programacion | A5 u otros anexos | Mejor enlazar repositorio y documentar estructura, build, pruebas y mantenimiento. |
| Manuales de usuario | A5 u otros anexos | Necesario si el producto debe ser instalado, usado o desplegado por terceros. |

```{tip}
Si vienes de una plantilla antigua, no la borres sin pensar. Primero clasifica cada apartado en memoria, anexo obligatorio, anexo opcional o material de repositorio.
```
