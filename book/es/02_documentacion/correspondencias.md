# Correspondencias antigua vs actual

La estructura actual no rompe con la antigua: la compacta, la adapta y cambia el peso de algunos documentos. Esta tabla ayuda a reutilizar buenas prácticas de ITIS/PFC sin seguir una estructura obsoleta.

| En la guía antigua | Encaje en la estructura actual | Comentario práctico |
|---|---|---|
| Introducción | Introducción de la memoria | Presenta dominio, motivación, problema y estructura del documento. |
| Objetivos del proyecto | Objeto y objetivos | Distingue objetivo principal, subobjetivos y objetivos personales si aportan valor. |
| Conceptos teóricos | Antecedentes / situación actual | Solo incluye teoría necesaria para entender el TFG. |
| Técnicas y herramientas | Métodos, herramientas y modelos | No listes herramientas obvias; explica las que afectan a decisiones técnicas. |
| Aspectos relevantes del desarrollo | Solución propuesta / organización | Debe explicar decisiones, problemas encontrados y evolución del trabajo. |
| Trabajos relacionados | Antecedentes / estado del arte | Especialmente importante en TFGs de investigación o con tecnología novedosa. |
| Conclusiones y líneas futuras | Conclusiones y trabajo futuro | Debe responder a los objetivos, no limitarse a cerrar con frases genéricas. |
| Plan del proyecto software | Gestión del proyecto / Anexo A3 | Planificación, hitos, esfuerzo, coste temporal y estimaciones. |
| Especificación de requisitos | Anexo A1 | Requisitos funcionales, no funcionales, historias, casos de uso o equivalentes. |
| Especificación de diseño | Anexo A2 | Arquitectura, modelo de datos, componentes, interfaces y decisiones de diseño. |
| Documentación técnica de programación | A5 u otros anexos | Mejor enlazar repositorio y documentar estructura, build, pruebas y mantenimiento. |
| Manuales de usuario | A5 u otros anexos | Necesario si el producto debe ser instalado, usado o desplegado por terceros. |

```{tip}
Si vienes de una plantilla antigua, no la borres sin pensar. Primero clasifica cada apartado en memoria, anexo obligatorio, anexo opcional o material de repositorio.
```
