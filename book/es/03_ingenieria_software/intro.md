# Ingenieria del software aplicada al TFG

Un TFG de Ingenieria Informatica no se evalua solo por que "funcione". Tambien se evalua por como se ha planteado, construido, documentado y defendido.

La Ingenieria del Software aporta lenguaje y estructura: requisitos, analisis, diseno, arquitectura, pruebas, gestion de configuracion, planificacion y mantenimiento. Este bloque no pretende repetir una asignatura completa; pretende traducirla a artefactos utiles para la memoria y los anexos.

Como recursos de referencia, el curso de Ingenieria del Software de Codigus y los materiales docentes del repositorio GRIAL ofrecen contenidos utiles sobre procesos, UML, diseno, pruebas y metodologias {cite:p}`codigus_ingenieria_sw,grial_is1_2022`.
