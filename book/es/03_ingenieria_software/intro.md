# Ingeniería del software aplicada al TFG

Un TFG de Ingeniería Informática no se evalúa solo porque "funcione". También se evalúa por cómo se ha planteado, construido, documentado y defendido.

La Ingeniería del Software aporta lenguaje y estructura: requisitos, análisis, diseño, arquitectura, pruebas, gestión de configuración, planificación y mantenimiento. Este bloque no pretende repetir una asignatura completa; pretende traducirla a artefactos útiles para la memoria y los anexos.

Como recursos de referencia, el curso de Ingeniería del Software de Codigus y los materiales docentes del repositorio GRIAL ofrecen contenidos útiles sobre procesos, UML, diseño, pruebas y metodologías {cite:p}`codigus_ingenieria_sw,grial_is1_2022`.
