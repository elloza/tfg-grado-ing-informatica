# Team Word

Word es una opción válida si se usa bien. El problema no es Word; el problema es cruzar ficheros por correo, perder comentarios, romper estilos o editar sin control de cambios.

## Flujo recomendado

- Mantener el documento en OneDrive o SharePoint.
- Usar estilos de título, texto, figuras y tablas.
- Activar control de cambios cuando haya revisión del tutor.
- Usar comentarios inline para dudas concretas.
- No resolver comentarios del tutor hasta que el tutor confirme que la corrección está bien.
- Usar Mendeley o Zotero para citas.
- Exportar a PDF solo cuando el documento esté revisado.

## Plantilla

Si se usa una plantilla Word no oficial, debe respetar portada, resumen, índices, estilos y normas de la Facultad/Departamento. La plantilla ayuda, pero no sustituye la revisión.
