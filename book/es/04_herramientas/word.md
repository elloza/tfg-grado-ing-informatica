# Team Word

Word es una opcion valida si se usa bien. El problema no es Word; el problema es cruzar ficheros por correo, perder comentarios, romper estilos o editar sin control de cambios.

## Flujo recomendado

- Mantener el documento en OneDrive o SharePoint.
- Usar estilos de titulo, texto, figuras y tablas.
- Activar control de cambios cuando haya revision del tutor.
- Usar comentarios inline para dudas concretas.
- No resolver comentarios del tutor hasta que el tutor confirme que la correccion esta bien.
- Usar Mendeley o Zotero para citas.
- Exportar a PDF solo cuando el documento este revisado.

## Plantilla

Si se usa una plantilla Word no oficial, debe respetar portada, resumen, indices, estilos y normas de la Facultad/Departamento. La plantilla ayuda, pero no sustituye la revision.
